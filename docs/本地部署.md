# 本地部署与日常使用

## 前置要求

| 软件 | 版本 | 用途 | 没装会怎样 |
|---|---|---|---|
| Python | 3.11+ | 后端 | 必装，[下载](https://www.python.org/downloads/)（勾选 Add to PATH）；没有的话「一键安装并启动.bat」会自动装 3.13 |
| Node.js | 18+ | 构建前端 | 可跳过，用 Releases 里的 dist 产物；「一键安装并启动.bat」会自动装 Node 22 |
| （可选）Playwright Chromium | - | 导出 PDF | 不装也能用网页打印视图 |

## 启动

Windows：双击 `start.bat`；Linux/macOS：`./start.sh`。
全新电脑想一步到位：双击 **`一键安装并启动.bat`**（检测并安装 Python / Node，然后调用 `start.bat`）。
起不来时先双击 **`检查环境.bat`**，它会指出是缺 Python、缺 Node、.venv 依赖损坏还是端口被占。

脚本做的事：创建/校验 `.venv` → 装依赖 → 构建前端 → 起服务在 **8100** 端口。
数据库自动创建在 `data/tiku.db`，默认是空库。

> **以前能打开、现在点 start 没反应？** 多半是 `.venv` 与当前 Python 版本对不上（例如 venv 是 3.12 建的，
> 但依赖装成了 3.13 的包）。现在的 `start.bat` 每次启动都会先 `import fastapi, uvicorn, fitz, PIL, docx, httpx`
> 自检，失败就自动删掉 `.venv` 重建并重装依赖，不需要你手动处理。

多端访问：平板/手机连同一 WiFi，打开 `http://<电脑IP>:8100`（查电脑 IP：Windows 运行 `ipconfig` 看 IPv4 地址）。界面自适应小屏。

> 把 `start.bat` 的快捷方式放进 `shell:startup` 文件夹即可开机自启。

## 日常操作流程

1. **加一本新课本（建纲）**：把课本 PDF 交给本地 Agent（见 [Agent拆解指南](Agent拆解指南.md)），产物放进 `data/inbox/`，
   在「资料库」页导入。导入后这本书出现在「资料库」并标记为课本·纲。
2. **加教辅/试卷**：同样方式拆解导入。所有题先进入「待审核」。
3. **审核**：打开「待审核」页 → 逐条「确认入池」；「疑似超纲」的题看完对纲说明后决定保留（标为提优）或驳回。
4. **组卷**：在「题库」页勾选题目（可整卷加入、跨页选），点「用所选组卷 →」，在页内托盘调序、按题型设分值后生成；
   也可以点「按教材自动组卷」按课本纲的单元范围和题型数量抽题。选中的题可一键「删除所选」。
   预览页可逐题「换一题」，然后打开「题目卷 / 答案卷 / 合卷」打印视图（内容可直接编辑并保存），再用浏览器打印为 PDF。
5. **打印**：A4 纵向。题目卷、答案卷分开打开，答案在答案卷；需要合卷时打开合卷视图。

## 出题页：文字选择、翻译、AI 文章重点

左栏顶部有两颗模式按钮：

- **框选裁剪**（默认）：在 PDF 页面上拖框，再点「裁剪到题目 / 裁剪到答案」，图片落到右侧画布。
- **选择文字 / 翻译**：PDF 上会出现透明文字层，可以像浏览器里一样拖选英文（跨行也行）。
  松开鼠标会弹出小窗，里面是精确提取出来的原文：
  - **复制**：拷到剪贴板；
  - **翻译成中文**：调用 DeepSeek，译文出现在下方输入框，可再改；
  - **插入题目 / 插入答案**：把原文或译文作为一个文本块放到对应画布，插入后继续拖到想要的位置。
  - 只想选一行时，直接点那一行即可，不需要拖。

画布上：

- 点空白处拖出选框，可一次选中多个元素；`Ctrl+A` 全选；`Shift+点击` 逐个加选。
- 选中文字后，工具栏 `A－ / A＋` 改字号（也可以给整组文字一起改）；选中图片时 `A＋/A－` 按比例缩放图片。
- 字体颜色：选中文字 → 选颜色 →「上色」；不选中时选的颜色会作为「新插入文字」的默认色。颜色会随版面保存。
- 文字块里可直接拖选任意单个字/字母，再改字号或颜色；同一段可混排多种字号/颜色，保存成题图后仍保留。
- 工具栏「对齐」把所有文字块的首字对到同一条竖线；「统一」把选中文字/文字块改成当前字号与颜色；
  「连句」把 PDF/OCR 抽出的硬换行连成整段（中文之间不插空格、英文保留空格），并设为两端对齐，一段排满再换行。
- 裁剪图插入后，选中图片点「固定图片」即锁定：图片不再拦截鼠标，压在图片上方的文字层可正常拖选单字/多字改字号、颜色或翻译；
  点图片右上角的 🔒 小按钮可重新选中该图，再点「解锁图片」恢复拖动/缩放。
- 选中图片点「橡皮擦」：白色笔刷涂掉水印/旧答案，保存后画布里的图片替换成擦好的版本；
- 在已固定的图片上按住鼠标右键拖动，可框选图内一小块，松手后识别该区域文字，支持复制或插入画布（原图不变）；
- 图片里的字本身是像素，不能直接改格式；选中图片点「图片转文字」可让本机 OCR 把整张图原地换成可编辑文字块
  （裁剪时可勾选「裁剪后识别为文字」自动执行），再改字号/颜色/翻译。
- 框选 PDF 文字只取浏览器实际选区，不再按整行扩写；想选一行直接点那一行。
- 翻译或摘录的文字插入画布时会先「连句」再按顺序往下排：放得下就新建一段，页面底部放不下就接到上一段末尾，
  不会叠在一起，也不会一段只占半行。
- 工具栏「翻译选中」：选中画布中的字/词或整个文字块，弹出翻译小窗，可替换选中文字、插入新文字块或复制译文。
- **AI 生成答案**：答案画布的「AI 生成答案」按题干、题型和题号小问解题，再做一遍「审题人」复核；
  答案、解析、参考文献会一起填进「参考答案」（没有查到文献就写「无参考文献」），可直接人工修改，
  也可「插入答案画布」继续排版。题目是图片时先走本机 OCR 读题；参考答案只保存在本题，不会覆盖原题。
- 页面滚动：PDF 视图、画布、摘要列表、弹窗和右侧信息栏各自滚动，滚到边界不会带动外面整页乱跑。

## 保存后的 AI 归类与解析

- 出题页点「保存到题库」时，AI 会按题目画布文字判断题型、难度和化学专题，并自动补上专题标签
  （如「有机化学」「电化学」），题库左侧分类里可直接按这些标签筛选；没配 Key 或调用失败时退回关键词规则，不影响入库。
- 右侧工具栏「AI 生成解析」：为当前题生成【思路】【解答】【易错点】并写入题目解析，题库里展开答案即可看到。
- 接口：`POST /api/ai/classify`、`POST /api/ai/analysis`；出题保存接口 `/api/authoring/compose` 支持 `auto_classify`。

## 不进题库的 AI 试卷、整卷导入与融合

- **分步出题（1–11 道，后台生成）**：出题页右上角「出题」→ 选 1–11，任务在后台运行，切走页面不会中断；回来会自动继续，第 1 题显示在题目/答案画布；
  可逐题改题干、答案、字号，点「出下一个题 →」继续，最后一题点「完成并生成试卷」。
  后端 `POST /api/papers/ai/preview` 只返回快照（`{items:[{snapshot,score}]}`，不写库），
  `POST /api/papers/ai/build` 再把逐题改好的快照建成试卷（`PaperQuestion.question_id` 为空），
  所以不占题库、试卷页不能换题，但可打印/导出/融合。
- **AI 出 N 题（旧入口）**：出题页「AI 出题」面板也可直接一次生成，走 `POST /api/papers/ai`。
- **整卷导入**：题库页「⤓ 导入题目 / 试卷」可一次选多份 PDF，也可把 PDF 拖进虚线框；
  题目卷和答案卷可以分开选。后端 `POST /api/import/papers` 把各份文字按 `=== 文档：文件名 ===` 合并，
  交给 `ai.parse_paper` 按题号配对题目与答案，再拆题、按 `_question_hash` 去重，
  建/找「化学」书册并把专题标签归入左侧分类。单份走 `POST /api/import/paper`。
  上传文件名用 `_clean_upload_name` 修复中文编码，中文文件名可直接选。
- **试卷融合**：试卷页勾选两套及以上 →「融合所选试卷」。后端 `POST /api/papers/merge` 按顺序拼接快照，
  从第二套起用 `_shift_number` 顺延大题号（`1-2` → `2-2`），小问号不变；`config.source` 记为 `merged`，
  试卷页副标题会显示「融合卷」。
- **可编辑打印/分卷**：`GET /api/papers/{id}/view?part=all|questions|answers` 输出可编辑打印页，
  `PATCH /api/papers/{id}/items` 保存标题、题干、答案、解析；`/export?part=questions|answers` 直接生成
  题目卷/答案卷 PDF（需 `playwright`，有系统 Edge/Chrome 时不必再下载 Chromium；没有就用浏览器打印）。
- 相关接口：`POST /api/papers/ai`、`/api/papers/ai/preview`、`/api/papers/ai/build`、`POST /api/papers/merge`、
  `POST /api/import/paper`、`POST /api/import/papers`、`POST /api/ai/ocr-image`。

## 配置 DeepSeek（翻译 / 生成答案 / 归类 / 解析 / 文献解读 / 整卷导入）

1. 到 <https://platform.deepseek.com> 申请 API Key；
2. 打开「设置 → AI 模型」，填入 Key（Base URL 默认 `https://api.deepseek.com`，模型默认 `deepseek-chat`）；
3. 点「测试连接」，显示往返耗时即成功；点「保存」后立即生效，不用重启。

Key 存在本地 `data/tiku.db` 的 `settings` 表；也可以用环境变量 `DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL` 覆盖（环境变量优先级更高，设置页会提示）。

### 用 DeepSeek Harness 的本机免费模型（不用 API Key）

装了 DeepSeek Harness 的免费模型插件后，站点可以直接借用本机网关：

1. 保持 DeepSeek Harness 运行（网关默认 `http://127.0.0.1:8326/v1`，Key 在 `~/.dsh/openai-gateway/api-key`）；
2. 打开「设置 → AI 模型」→ 点「检测免费模型插件」→ 选模型（默认 `our-free-model/deepseek-v4.1-flash-free`）→「使用免费模型」；
3. 点「测试连接」确认可用。之后翻译、生成答案、归类解析、文献解读都走免费模型。

免费通道只记在 `settings` 表里，付费 Key/Base URL/模型原样保留；点「切回付费 Key」即可恢复。程序不会把网关 Key 复制进数据库，而是每次调用时读取文件，所以插件轮换 Key 后不用重配。也可以用 `DSH_GATEWAY_URL` 环境变量改网关地址。检测接口：`GET /api/ai/free-models`。
使用 AI 功能时只发送选中的文字、当前页文字行、题目画布文字或已有答案，以及你主动用于 AI 出题/分步出题/整卷导入的素材文字（或指定 PDF 提取/OCR 出的文字，多份会合并后一次发送）；不会上传 PDF 原件或页面图片。

## 首页 AI 对话

首页顶部有对话卡片，助教人格叫「小卷」：像高校教务处/编辑部里做过多年资料整理的年轻助教，温和、干练、先给结论再给步骤，不奉承、不卖萌、不确定会直说。既能问「怎么出题 / 怎么组卷 / 整卷怎么导入 / 免费模型怎么开」，也能像普通 AI 一样问化学、写作、编程、常识等通用问题。后端把人格设定、项目功能、页面路径和操作流程作为系统提示交给当前 AI 模型。

- `POST /api/ai/chat`：一次性返回 JSON；
- `POST /api/ai/chat/stream`：SSE 逐字输出（`meta` 来源 → `delta` 增量 → `done` / `error`）；
- `search: true` 时先调用 `services/web_search.py` 抓取 Bing RSS（标题/链接/摘要，不抓正文），把结果作为参考资料交给模型，并在答案中要求标注 `[1]` 等来源；
- 限制：40 条消息、总计 60000 字符、单条 8000 字符，回复上限 2600 tokens；
- 使用「设置 → AI 模型」里选择的模型；免费模型同样要求 DeepSeek Harness 在后台运行。

搜索是公开网页摘要，可能不完整或过期；没有付费搜索 API 的实时性保证。要换搜索源可改 `web_search.py` 里的 `BING_RSS`。

## PDF 导出增强（可选）

```bash
.venv\Scripts\pip install playwright

```

装好后「下载 PDF」按钮直接生成文件；没装时该按钮会提示改用打印视图（浏览器 Ctrl+P → 另存为 PDF，效果相同）。

## 常见问题

- **端口被占**：改 `start.bat` 里 `--port 8100` 为其他端口。
- **点了 start.bat 窗口一闪就没 / 浏览器打不开**：
  1) 先双击「检查环境.bat」；2) 看窗口里是哪一步报错（Python / 依赖 / 前端 / 端口）；
  3) 如果是 `.venv` 依赖坏了，再跑一次 `start.bat` 就会自动重建；4) 仍然不行时，看 `data\server.log`（计划任务/隐藏启动模式会写这个文件）。
- **AI 报 401 / 402**：Key 填错或余额不足，到 DeepSeek 控制台检查；改完点「测试连接」。
- **AI 读不出某一页**：扫描页会先跑本机 OCR；仍失败时会明确提示，请改用「框选裁剪」把整页/局部裁成图片再排版。
- **Python 找不到**：Windows 商店的 python 是假的，去 python.org 重装并勾选 Add to PATH。
- **重置数据**：停服后删除 `data/tiku.db`，重启会自动重建（空库）。
- **想迁移到另一台电脑**：拷贝整个 `data/` 目录即可（数据库+题图都在里面）。
