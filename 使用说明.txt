tiku-studio —— 文献命题工作台（源码包）
========================================

一、这是什么
  面向高校教师的出题/组卷/导出工具：把文献或试卷 PDF 裁剪成题图，
  在画布里自由排版（可加公式、文字、页眉页脚），存进题库，再组卷导出
  Word / PDF / Markdown。前端 Vue3 + Vite，后端 FastAPI + SQLite。

二、最快跑起来（Windows，推荐）
  刚拿到包、不确定环境？按这个顺序：

  1) 先双击 检查环境.bat     —— 只检查、不安装，看结论那一行
  2) 再双击 一键安装并启动.bat —— 缺什么自动装什么，装完自动开浏览器

  它会：
    · 找 Python 3.11+；没有就自动从清华镜像下载 3.13.9 并静默安装
      （All Users + 加入 PATH，约 27MB，需要联网；装完若仍找不到，重启一次电脑再双击）
    · 建 .venv 并安装后端依赖（走清华 PyPI 镜像）
    · 检查前端 dist；缺失才去装 Node 22 并 npm install + build
    · 启动服务并打开 http://127.0.0.1:8100

  也可以手动：
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r apps/api/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
    python -m uvicorn app.main:app --app-dir apps/api --host 0.0.0.0 --port 8100

  start.bat 每次启动都会自检 .venv：
    · 如果依赖缺失，或 .venv 与当前 Python 版本不匹配（以前的典型症状：窗口一闪、
      浏览器打不开，日志里出现 pydantic_core / ArgsKwargs 之类的 ImportError），
      会自动删掉 .venv 重建并重装依赖，不需要手动删目录；
    · 想先看问题出在哪，双击「检查环境.bat」。

三、目录
  check  检查环境.bat            环境自检（只读，不改系统）
  setup  一键安装并启动.bat       自动安装缺失组件并启动
  apps/api            FastAPI 后端（app/ 下 routers、services、models）
  apps/web            Vue3 前端（src/views、src/components、src/*.js）
  apps/web/dist       已构建好的前端（不想装 Node 也能直接跑）
  apps/api/tests      pytest 用例
  docs/screenshots    界面截图
  data（不存在）       运行后自动生成：tiku.db、library/ 题图、server.log

四、改前端
    cd apps/web
    npm install
    npm run dev        # 开发服务器（改完刷新即可，HMR）
    npm run build      # 产出 apps/web/dist，后端直接托管

五、改后端
    代码在 apps/api/app。改完重启 uvicorn 即可；
    表结构变更请写在 app/db.py 的 _migrate() 里（幂等），不要手改库。

六、测试
    .venv\Scripts\python.exe -m pytest apps/api/tests -q

七、注意
  1) 源码包里没有 .venv / node_modules / data（体积与隐私考虑）。
  2) data 目录保存的是你自己的题库与题图，别误删；换目录可在「设置 → 数据位置」里改
     （改完约 1 分钟自动重启，会把现有数据库复制过去，不删旧数据）。
  3) 图片和文档只在本地处理，不上传任何内容到外部服务。
  4) 许可证：MIT（含上游 cy-0754/tiku-studio 的版权声明，见 LICENSE）。

八、出题页怎么用（v0.12 新增）
  左栏顶部两颗模式按钮：
    · 框选裁剪（默认）：在 PDF 上拖框 → 点「裁剪到题目 / 裁剪到答案」。
    · 选择文字 / 翻译：PDF 上直接拖选英文（可跨行），松手弹出小窗：
        - 复制：把原文拷到剪贴板；
        - 翻译成中文：调用 DeepSeek，译文可再修改；
        - 插入题目 / 插入答案：原文或译文作为文本块放进对应画布。
      只想选一行时直接点那一行，不用拖。

  右侧画布：
    · 点空白处拖出选框可批量选中；Ctrl+A 全选；Shift+点 逐个加选。
    · 选中文字后 A－ / A＋ 改字号；选中图片时 A＋ / A－ 按比例缩放。
    · 字体颜色：选中文字 → 取色 → 上色；不选中时取的颜色用于新插入文字。
      颜色会随版面一起保存。
    · 文字块里可直接拖选任意单个字/字母（或几个字），再点 A－ / A＋ 或「上色」，
      只改这一段的字号/颜色，同一段里可以混排多种颜色和字号；保存成题图后仍然保留。
    · 工具栏「对齐」：把所有文字块的首字对到同一条竖线上；
      「统一」：选中若干文字或整个文字块后，统一改成当前字号/颜色；
      「连句」：把 PDF/OCR 抽出来的「一行一个换行」连成整段，一段排满再换行，中文之间不插空格，
      英文字间保留空格，并自动改成两端对齐，避免右边空一大片。
    · 裁剪图插入后，选中图片点「固定图片」：锁住后不能拖动/缩放，
      图片也不会挡住下面的文字，可直接拖选盖在图片上方的文字层；点图片右上角 🔒 可重新选中图片。
      要改图片里的字：选中图片点「图片转文字」，本机 OCR 会把整张图原地换成可编辑的文字块，
      再改字号/颜色/翻译；裁剪时可以勾选「裁剪后识别为文字」自动做这一步。
      注意：图片里的字本身是像素，不 OCR 成文字块就不能直接改格式。
    · 框选 PDF 文字时只取你实际选中的那一段（不再按整行扩写）；想选一行直接点那一行。
    · 工具栏「翻译选中」：选中画布里的文字（可只选几个单词）或选中文字块，
      点它弹出翻译小窗，可替换选中文字、插入新文字块或复制译文。
    · 「AI 逐页精读」：先在面板里选起始页和要读几页（1/2/4/8/到末尾），
      AI 逐页读完每一页：每页给 2-4 句中文摘要，再挑出机理研究、反应路径、
      结构解释、关键结论等「重点句」。左侧「AI 逐页精读」面板固定显示每页摘要，
      点摘要里的重点条会跳到对应页，并在页面上画黄色重点线，方便直接框选。
      注意：扫描版 PDF 会自动调用本机 OCR（需 rapidocr_onnxruntime，首次每页约十几秒）；识别不出时仍可直接框选裁剪成图片。
    · 答案画布：点「AI 生成答案」，AI 会按题干和题号小问（1-1、1-2…）解题，并自动复核一遍；
      答案、解析、参考文献会一起填进「参考答案」（没有查到文献就写「无参考文献」），可以直接修改；
      点「插入答案画布」可排到答案页上。
    · 翻译或摘录的文字插入画布时先「连句」再按顺序往下排：放得下就新建一段，
      页面底部放不下就接到上一段末尾，不会几个块叠在一起，也不会一段只占半行。

  · 分步出题（出 1-11 道）：
      1) 点右上角「出题」（或右下「AI 出题」面板的「出题…」），弹出数字 1-11，选这次要出几道；
      2) AI 按素材一次生成，第 1 题直接显示在题目画布，答案/解析显示在答案画布，可直接改题干、答案、字号；
      3) 改完点右上角「出下一个题 →」；最后一题按钮变成「完成并生成试卷」，点完自动打开试卷页；
      4) 生成的题只进试卷、不写题库，可命名、打印、导出或与别的卷融合；中途点「退出」会丢弃本次分步出题。

九、配置 DeepSeek（翻译 / 逐页精读 / 生成答案 / 自动归类 / 解析）
  1) 到 https://platform.deepseek.com 申请 API Key；
  2) 打开「设置 → AI 模型」，填 Key（Base URL 默认 https://api.deepseek.com，
     模型默认 deepseek-chat）；
  3) 点「测试连接」→ 显示往返耗时即成功；点「保存」立即生效，不用重启。
  也可以用环境变量 DEEPSEEK_API_KEY / DEEPSEEK_BASE_URL / DEEPSEEK_MODEL 覆盖。
  没有付费 Key 时，可以用本机免费模型：
  a) 确认「DeepSeek Harness 免费模型插件」已安装并启用，保持 DeepSeek Harness 在运行；
  b) 打开「设置 → AI 模型」→ 点「检测免费模型插件」→ 选一个模型 →「使用免费模型」；
  c) 不用填 Key（Key 由插件放在本机，程序每次调用时读取，插件轮换 Key 也不用重配）。
  免费通道和付费 Key 可以来回切：点「切回付费 Key」恢复原来的 DeepSeek 配置，原 Key 不会被覆盖。
  免费模型的额度由插件提供；如果检测不到，先确认 DeepSeek Harness 正在运行、插件已启用。
  Key 只存在本地 data/tiku.db，不会上传；翻译只发送选中的文字，
  逐页精读只发送当前页的文字行，生成答案只发送题目画布文字与已有答案，
  归类只发送题目画布文字，解析只发送题干与答案，AI 出题只发送你给出的素材或指定 PDF 的文字，
  整卷导入只发送该卷提取/OCR 出的文字；都不上传 PDF 原件或图片。
  竞赛题排版：题号、分值、小问（1-1、1-2…）可以整段裁剪，也可以裁剪图 +「＋文本」
  混排；题型默认「综合」，保存时 AI 会按内容再归类。

十、题库里怎么组卷（原「组卷」页已并入题库）
  1) 打开「题库」，勾选题目（可跨分页、可「整卷加入已选」）；
  2) 点选择栏右侧「用所选组卷 →」，在弹出的托盘里用 ↑ / ↓ 调整顺序、
     移除不要的题、按题型设置每题分值，总分实时累加；
  3) 点「生成试卷」直接打开试卷预览，可继续「继续编排」、打印或导出；
     试卷页提供「题目卷 / 答案卷 / 合卷」三种可编辑打印视图，标题、题干、答案、解析
     都能在页面上直接改，改完点「保存修改」再打印或另存 PDF。
  选择栏还有「删除所选」：勾选后一键删除（会二次确认，删了不能恢复）。
  也可以点「按教材自动组卷」：选课本纲、单元范围、题型数量，系统自动抽题；
  需要先在「资料库」导入课本纲（role=textbook）。
  说明：出题页「保存到题库」时，AI 会自动判断题型/难度/化学专题并打上标签
  （专题标签如「有机化学」「电化学」会出现在题库左侧分类里）；
  右侧工具栏还有「AI 生成解析」，可把【思路】【解答】【易错点】写进题目解析。
  没有配置 Key 时，归类会退回到关键词规则，入库不受影响。

十一、不出题库、直接生成试卷；整卷导入；试卷融合
  1) 分步出题：点右上角「出题」→ 选 1–11 道 → AI 一次生成后逐题显示；
     每道题可以直接改题干/答案/字号，改完点右上角「出下一个题 →」，
     最后一题点「完成并生成试卷」，系统自动建一套试卷并打开，不写进题库。
     生成后可以打印、导出题目卷/答案卷，也可以与别的卷融合。
     素材优先用「题干文字」和当前页的 AI 摘要；都没填时会读当前整份 PDF（较慢）。
     中途点「退出」会丢弃这次分步出题，不会留下半套卷。
  2) 整卷导入：题库页「⤓ 导入题目 / 试卷」→ 可一次选多份 PDF（也可以直接把 PDF 拖进虚线框），
     题目卷和答案卷可以分开选；扫描页自动 OCR，AI 合并后按题号把题目与答案配对、
     拆成一道道题，自动归入「化学」书册和对应专题；重复题会自动跳过，中文文件名可直接选。
  3) 融合试卷：试卷页勾选两套及以上，填融合卷名，点「融合所选试卷」；
     第二套起大题号自动顺延（例如 1-2 变成 2-2），小问号不变，可继续打印或导出。
  4) 题目卷/答案卷：试卷页分别打开两种打印视图，内容可在页面上直接编辑，点「保存修改」生效；
     点「下载题目卷 / 下载答案卷」直接生成两份 PDF（题目卷不含答案，答案卷不含题干）；
     也可以用浏览器打印为 PDF（服务器已装 Playwright，借用本机 Edge/Chrome 生成）。
  说明：直接生成的题不占题库，所以试卷页不能对它们「换题」；需要长期使用请把题保存到题库。

十二、首页 AI 助教「小卷」（刚来先问它）
  1) 打开首页，顶部就是 AI 助教「小卷」；可以直接输入问题，也可以点推荐问题；
  2) 小卷的人设：像高校教务处/编辑部里做过多年资料整理的年轻助教，
     温和、干练、先给结论再给步骤；不奉承、不卖萌、不懂会直说；
  3) 它既熟悉本站功能、页面和操作步骤（比如「怎么从 PDF 出一道题？」
     「题库怎么组卷导出？」「整卷 PDF 怎么导入？」），也可以像普通 AI 一样
     回答化学、写作、编程、常识等通用问题；
  4) 回答是逐字输出的；输入框上方有「联网搜索」开关，勾上后会先搜 Bing，
     回答里会标注 [1][2] 并在气泡下方列出网页来源，适合问最新消息；
     不勾选时只用模型已有知识，可能不是最新信息；
  5) 回答用的是「设置 → AI 模型」里当前选中的模型；搜索只取标题、链接和摘要，
     不抓网页全文，结果可能不完整或过期，重要信息请点来源自行核对；
     用本机免费模型时，需要 DeepSeek Harness 和免费模型插件在后台运行；
  6) 对话只保存在当前页面，点「清空」可重开；支持多轮和较长内容，
     但整段对话超过 6 万字或 40 条时请开新对话；AI 回答仅作参考，
     具体按钮和页面以实际界面为准。
