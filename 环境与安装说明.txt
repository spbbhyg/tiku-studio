tiku-studio 环境与安装（Windows）
=================================

两个批处理都可以直接双击，不需要命令行经验：

  检查环境.bat        只检查：Python / Node / 依赖 / 端口，输出 OK / 错误 / 提示 三种结论
  一键安装并启动.bat   缺什么装什么，然后交给 start.bat 启动服务

它们做了什么（没有黑魔法）
  1. 依次尝试 py -3.13、py -3.12、py -3、python，用 `import sys; sys.version_info >= (3,11)` 判定
  2. 不满足时下载 https://mirrors.tuna.tsinghua.edu.cn/python/3.13.9/python-3.13.9-amd64.exe
     （失败自动换华为云 / 官网镜像），以 /quiet InstallAllUsers=1 PrependPath=1 静默安装
  3. 前端 dist 缺失时才去装 Node 22（npmmirror 的 msi，/qn 静默）
  4. 最后调用 start.bat：它每次启动都会 import 自检 .venv，缺包或与 Python 版本不匹配时
     自动重建并重装依赖（清华镜像失败会换官方源），再启动 uvicorn（8100 端口），
     等 3 秒后打开浏览器；关掉窗口即停止服务
  5. 依赖里包含 rapidocr_onnxruntime（扫描件 OCR，首次安装约多 60–100 MB）；
     它让「AI 逐页精读 / AI 生成答案」也能读扫描 PDF，装不上时其他功能不受影响

卸载/还原
  · 程序本身：直接删掉解压出来的目录即可，不写注册表、不装服务
  · 自动装过的 Python：控制面板 → 程序和功能 → Python 3.13.9
  · 自动装过的 Node：控制面板 → 程序和功能 → Node.js
  · 数据：整个 data 目录，删掉即清空（题库、题图、日志）

已知限制
  · Windows 10 1809+，64 位；需要联网（镜像可达）
  · 若公司网络拦截了镜像，把报错行发给维护者，或手动装 Python 3.11+ 后只用 start.bat
